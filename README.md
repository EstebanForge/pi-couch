# Pi Couch

A phone-first web client for the pi coding agents running on my server.

I tunnel in over Tailscale, load the UI, and work from the phone: watch every session on the machine (including the ones I started over ssh), steer them, review diffs, and leave line comments for the agent. Back at the desk I retake control over ssh in the same sessions. Nothing gets locked into the UI.

Status: planning. The plan lives in [docs/PLAN.md](docs/PLAN.md).

Built on [Pi Durable](https://earendil.com/posts/pi-durable/). Inspired by the private phone setup Mario Zechner built for himself.
